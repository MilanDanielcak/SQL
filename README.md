# Project Overview
This project was developed as part of a Data Technician bootcamp to demonstrate proficiency in SQL for data analysis. The primary goal was to transform raw retail and sales datasets into actionable business insights by leveraging relational database management techniques and structured query language.

## Key Skills & Technical Proficiencies
Throughout this project, I applied the following core SQL concepts to query, filter, aggregate, and analyze complex datasets:

*   **Data Retrieval:** Utilized `SELECT` statements to extract specific columns and refine output.
*   **Data Filtering:** Applied `WHERE` clauses to isolate records based on customer demographics, sales regions, and transaction dates.
*   **Data Sorting:** Used `ORDER BY` to identify top-performing products and peak sales periods.
*   **Data Aggregation:** Employed `GROUP BY` alongside aggregate functions (`SUM`, `AVG`, `COUNT`) to calculate revenue metrics, sales volume, and customer spending habits.
*   **Relational Database Management:** Performed complex `JOIN` operations (`INNER JOIN`, `LEFT JOIN`) to combine disparate tables, such as linking `Products`, `Transactions`, and `Customers` to create a holistic view of the sales lifecycle.

## Project Highlights
By structuring these queries, I successfully extracted key insights, including:
*   **Sales Performance:** Identifying high-margin products and seasonal sales trends.
*   **Customer Segmentation:** Analyzing purchase patterns to help refine marketing strategies.
*   **Operational Efficiency:** Identifying bottlenecks in the supply chain by tracking transaction timestamps against inventory records.
